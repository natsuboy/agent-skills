# Timeline 模板库

本文档提供 Mermaid Timeline (时间线) 的标准模板，用于可视化历史事件、项目里程碑和演进过程。

**适用场景**：
- 历史事件回顾
- 产品版本发布记录
- 项目里程碑规划
- 个人/公司成长历程

---

## 模板1：产品发布历史（评分：95分）⭐⭐⭐⭐⭐

**适用场景**：版本迭代记录、更新日志可视化

```mermaid
timeline
    title APP产品迭代历史
    2022 : Q1 : 项目启动
         : Q2 : 内测版本发布
         : Q3 : 公测上线
         : Q4 : 用户突破10万
    2023 : Q1 : 推出会员功能
         : Q2 : 接入AI助手
         : Q3 : 国际版发布
         : Q4 : 获得年度最佳应用
    2024 : Q1 : 架构重构
         : Q2 : 支持深色模式
```

**特点**：
- 使用年份作为主要时间轴
- 每个时间点包含多个事件
- 清晰展示发展脉络

## 模板3：项目开发阶段（评分：90分）⭐⭐⭐⭐

**适用场景**：项目规划、阶段性成果展示

```mermaid
timeline
    title ERP系统开发计划
    一月 : 需求调研
         : 竞品分析
         : 确定技术选型
    二月 : 原型设计
         : 数据库建模
         : 核心模块开发
    三月 : 前端页面开发
         : 接口联调
         : 首轮测试
    四月 : 修复Bug
         : 压力测试
         : 正式上线
```

**特点**：
- 以月份为单位

## 语法参考

### 基本结构
```mermaid
timeline
    title 标题
    时间点1 : 事件1
            : 事件2
    时间点2 : 事件3
```

### 样式
Timeline 图表自动适配 Mermaid 主题。可以通过 `%%{init: {'theme': 'base', 'themeVariables': { ... }}}%%` 进行微调。

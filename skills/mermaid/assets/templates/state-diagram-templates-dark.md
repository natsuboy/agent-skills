# State Diagram Dark 模板库

本文档提供适用于深色背景编辑器的高质量状态图模板，可直接复制使用。

**使用场景**：
- Dark 模式编辑器（如 VS Code Dark、JetBrains Darcula 等）
- 演示文稿中的深色幻灯片
- 深色主题的博客或文档网站

---

## 模板1：简单状态机（评分：87分）⭐⭐⭐⭐

**适用场景**：基础状态机、简单生命周期

```mermaid
%%{init: {'theme':'dark'}}%%
stateDiagram-v2
    [*] --> 空闲
    空闲 --> 处理中 : 开始
    处理中 --> 完成 : 成功
    处理中 --> 失败 : 错误
    完成 --> [*]
    失败 --> 空闲 : 重试
    失败 --> [*] : 放弃
```
